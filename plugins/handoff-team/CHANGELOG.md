# Changelog

## 1.2.0

Weeks 4-8 and a Chrome-only start (not yet released):
- **Training cards** (Week 4): the Chief drafts a training as a Needs-you note; Team View adds it, both copies, only after the owner opens every step and title, never with hidden characters, never under a built-in or taken name. Template: CLAUDE.md rule 11 and the make-a-training training. Hire cards follow the same rules.
- **Phone summary**: a cloud shift may send its end-of-shift summary to the owner's phone (PushNotification).
- **Brains copied from the GitHub template**: in Anthropic's cloud an unpinned brain saves to the repository it was cloned from, only after GitHub confirms the copy is private; on a Mac, Team View offers Use your cloud copy only for a private copy the signed-in owner runs, and Your cloud copy is public otherwise.
- After a Safety update the Chief is told to re-read CLAUDE.md.

## 1.1.0

Ready for new members from an empty folder (not yet released):
- Team View offers **Make my brain** or **Practice brain** in an empty folder; the brain template ships with the add-on.
- Guided setup: backup to a private GitHub copy (Apple's tools, GitHub's helper, sign-in code, pinned copy), connected apps approved inside setup, the About My Business interview, the first brief, the cloud morning shift (steps copied, claude.ai's page opened), chimes. Progress is saved per brain.
- Drafts only by default: messages to people become Gmail drafts the owner sends; Send buttons only when `sendFromTeamView` is on.
- **Safety update**: newer guard, rules, job cards and built-in trainings for existing brains, on the owner's tap, never through a link.
- Template fixes: drafts state only facts written in the brain, no made-up clock times, the brief is updated at the end, a practice brain never opens the real inbox, plain cloud save commands, and backup keeps only the brain's own `.claude` files.
- Gate: instruction files (CLAUDE.md, AGENTS.md, GEMINI.md and variants, look-alike letters folded), invisible characters in note names and on cards, and plain reasons for apps not yet OKed.
- While Team View offers to make a brain, only reading goes on in that folder until the owner taps (Codex round 11).
- Drafts only is read fresh from the brain when a message is held and right before a send; with it off, earlier Send cards show no Send (Codex round 11).
